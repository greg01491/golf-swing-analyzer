# v0.1.21

## Swing-plane line angles

- Each swing-plane reference line shows its own angle, measured from horizontal
  in the recorded image.
- Where two visible lines cross, a box at the crossing shows the angle between them.
  Lines that do not cross do not get a comparison, so there is nothing to pair up.
- A panel below the recording lists every line angle and crossing angle. Each one
  can be shown or hidden individually.
- Angle labels and crossing boxes start in staggered positions so they do not sit on
  top of each other, and can be dragged anywhere. Reset label positions returns them
  to the automatic layout without changing which ones are hidden.
- Label visibility and positions are remembered for each camera between sessions.
- Hold Shift while dragging a line handle to snap the line to 5° steps.
- Lines and labels stay aligned with the recording in portrait and landscape clips.

Angles are 2D measurements of the camera image, not true 3D swing-plane angles.
They depend on camera position and lens, so compare them between swings recorded
from the same camera setup.

Line positions are now stored relative to the recording rather than the surrounding
viewer, so lines saved in earlier versions may shift once in Pro Mode and need to be
repositioned.

## Installing over an existing installation

Close Golf Swing Analyzer, download `Golf-Swing-Analyzer-Setup-0.1.21.exe` from this
release, and run it using the same Windows account as your existing installation.
There is no need to uninstall first. Keep a backup of your configuration, calibration,
and swing data before updating.

## Validation

- Only the frontend changed since v0.1.20. 23 frontend tests, frontend lint, and the
  TypeScript/Vite build passed locally; backend and frontend CI passed on the release
  pull request.
- Browser validation used synthetic portrait and landscape recordings to check line
  and crossing angles, label hide/show, dragging and reset, line editing, Shift
  snapping, and narrow-window layout. Real session footage was not re-tested.
