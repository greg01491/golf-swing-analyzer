# v0.1.16

Hotfix for installed-app failures reported after v0.1.15.

- Pose inference now defaults to one worker instead of processing both camera videos in parallel. A two-worker override remains available on higher-memory systems.
- Memory exhaustion errors now recommend sequential inference, closing memory-heavy applications, and reducing camera resolution/FPS if needed.
- Slow-motion rates between pause and Chromium's minimum supported nonzero playback rate now clamp safely instead of throwing `NotSupportedError`.

Install this build to test repeated capture and processing on the rig. These changes reduce peak memory pressure but do not increase available Windows RAM/pagefile. If processing still exhausts memory, close other applications or reduce the camera mode and rerun the separate physical calibration-validation protocol.

The calibration and ground-reference workflow is still unverified on the physical rig. This release does not certify shoulder/hip measurement accuracy.
