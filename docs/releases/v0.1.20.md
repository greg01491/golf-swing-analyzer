# v0.1.20

## Clearer swing review

- Down-the-line and face-on recordings now have equal-sized viewing areas in Pro Mode.
  The full image is visible at reset view, with padding rather than stretching or cropping.
- Play/pause, the timeline, and frame controls sit below the recordings, leaving the
  ball unobstructed. Play/pause uses an icon rather than a text label.
- Each camera has independent zoom, drag-to-pan, Reset view, and full-screen controls.
  Framing is retained when changing review modes or toggling the skeleton overlay
  within a swing, and resets when opening another swing.
- Ball markers, review markers, and swing-plane lines move with the recording.
  Line handles can still be edited without dragging the camera image.
- Shared playback preserves synchronized frame stepping, slow motion, looping, and
  checkpoint navigation. Playback failures are reported explicitly.

## Other included work

This release also includes the existing calibration, tracking/metrics, manual-review,
camera-timing, and diagnostic changes from this working branch:

- Expanded manual observation review and diagnostic what-if analysis.
- Reconstruction evidence and metric-quality handling improvements.
- Camera capture/rotation and frame-timing improvements.
- Crown tracking/triangulation diagnostics and calibration-board print assets.

Diagnostics and saved review labels do not establish that calibration or measurements
are physically accurate. Continue to follow the calibration-validation checklist and
the confidence warnings shown in the app.

## Installing over an existing installation

Close Golf Swing Analyzer, download `Golf-Swing-Analyzer-Setup-0.1.20.exe` from this
release, and run it using the same Windows account as your existing installation.
There is no need to uninstall first. Keep a backup of your configuration, calibration,
and swing data before updating.

## Validation

- 302 backend tests and 18 frontend tests passed locally.
- Backend Ruff and Black checks, frontend lint, and the TypeScript/Vite build passed.
- Browser validation used saved portrait/landscape recordings and checked transport,
  independent framing, line editing, keyboard interaction, source/mode retention,

- Fresh hardware capture and physical calibration accuracy were not re-certified by
